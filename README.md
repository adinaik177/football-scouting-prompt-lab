# Football Scouting Prompt Evaluation Lab

## Problem
Football scouting reports generated by AI may contain unsupported conclusions,
inconsistent formats and invented information.

## Objective
To compare different prompting techniques and develop a more reliable prompt
for AI-assisted player analysis.

## Prompt Versions
1. Basic zero-shot prompt
2. Role-based prompt
3. Structured production prompt

## Dataset
Five synthetic football-player profiles were created for testing. No real
player or confidential club data was used.

## Evaluation
The prompts were compared for factual grounding, numerical evidence, format
compliance, tactical relevance and acknowledgement of limitations.

## Limitations
The data is synthetic and does not include league averages, physical data,
video analysis or contextual match information.
